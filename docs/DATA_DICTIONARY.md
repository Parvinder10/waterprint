# WATERPRINT: Data Dictionary

This document provides complete, unambiguous schema definitions for all time-series telemetry streams, static asset tables, network topology descriptors, and analytical output tables utilized in the **WATERPRINT** platform.

---

## 1. Flow Inflow Records (`dma_flow_records.csv`)

Primary high-frequency time-series recorded by electromagnetic insertion/flanged meters installed at the inlet and outlet boundaries of District Metered Areas (DMAs).

| Field Name | Type | Physical Unit | Nullable | Valid Physical Range | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `timestamp` | Datetime (UTC) | ISO 8601 string | No | `2024-01-01` to `2025-12-31` | Measurement timestamp resampled at uniform 15-minute intervals. |
| `dma_id` | String | Categorical | No | `[DMA_NORTH, DMA_SOUTH, DMA_CENTRAL]` | Identifier of the hydraulically isolated district metered area. |
| `flow_rate` | Float | $m^3/h$ | No | $[0.0, 500.0]$ | Instantaneous volumetric water flow rate entering the DMA. |
| `flow_accumulated` | Float | $m^3$ | No | $\ge 0.0$ | Cumulative volumetric index reading of the meter. |
| `meter_status` | String | Categorical | No | `[OK, FLATLINE, OUT_OF_RANGE, RATE_SPIKE, DROP]` | Operational status flag generated by the sensor health engine. |

## 2. Pressure Sensor Records (`pressure_sensor_records.csv`)

Continuous piezoresistive pressure transducer recordings deployed at strategic junction nodes across the distribution grid.

| Field Name | Type | Physical Unit | Nullable | Valid Physical Range | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `timestamp` | Datetime (UTC) | ISO 8601 string | No | `2024-01-01` to `2025-12-31` | Synchronized 15-minute measurement timestamp. |
| `node_id` | String | Identifier | No | e.g. `n1`, `n2`, `...`, `n33` | Junction node identifier mapped to EPANET network topology. |
| `pressure_head` | Float | $m$ ($mH_2O$) | No | $[5.0, 90.0]$ | Measured hydraulic pressure head above ground elevation. |
| `pressure_bar` | Float | $bar$ | No | $[0.5, 9.0]$ | Pressure converted to bar ($1\text{ bar} \approx 10.197\text{ mH}_2\text{O}$). |
| `sensor_battery` | Float | $\%$ | Yes | $[0.0, 100.0]$ | Battery state of telemetry RTU / data logger. |
| `pressure_status` | String | Categorical | No | `[OK, FLATLINE, OUT_OF_RANGE, TRANSIENT_NOISE]` | Sensor health indicator. |

---

## 3. Smart Meter Customer Consumption (`smart_meter_consumption.csv`)

Aggregated customer consumption records collected from Advanced Metering Infrastructure (AMI) / Automated Meter Reading (AMR) residential and commercial endpoints.

| Field Name | Type | Physical Unit | Nullable | Valid Physical Range | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `timestamp` | Datetime (UTC) | ISO 8601 string | No | `2024-01-01` to `2025-12-31` | Resampled hourly / 15-minute time boundary. |
| `dma_id` | String | Categorical | No | `[DMA_NORTH, DMA_SOUTH, DMA_CENTRAL]` | DMA where customers are connected. |
| `customer_category` | String | Categorical | No | `[RESIDENTIAL, COMMERCIAL, INDUSTRIAL, PUBLIC]` | Consumer classification for tariff and demand profiling. |
| `metered_consumption` | Float | $m^3/h$ | No | $\ge 0.0$ | Sum of registered water consumption across active customer meters. |
| `active_meters_count`| Integer | Count | No | $\ge 1$ | Number of reporting smart meters during the period. |

## 5. Ground Truth Leak Registry (`leak_ground_truth.csv`)

Calibrated benchmark leak scenarios used strictly for model evaluation and benchmarking.

| Field Name | Type | Physical Unit | Nullable | Description |
| :--- | :--- | :--- | :--- | :--- |
| `leak_id` | String | Identifier | No | Unique leak event ID (e.g. `LK_2024_001`). |
| `target_node_id` | String | Identifier | No | Closest junction node to the pipe breach. |
| `target_pipe_id` | String | Identifier | No | Pipe segment suffering structural failure. |
| `dma_id` | String | Categorical | No | Affected DMA zone. |
| `start_time` | Datetime | ISO 8601 | No | Exact timestamp when leak began opening. |
| `end_time` | Datetime | ISO 8601 | No | Timestamp when leak was isolated/repaired. |
| `leak_flow_rate` | Float | $m^3/h$ | No | Maximum flow rate escaping through the leak aperture. |
| `leak_type` | String | Categorical | No | `[INCIPIENT, BURST]` (gradual development vs abrupt rupture). |
| `pipe_diameter` | Float | $mm$ | No | Diameter of the host pipe. |

## 6. Analytical Output Schema (`anomaly_events.csv`)

Generated by WATERPRINT's ensemble anomaly detection and localization pipeline.

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `event_id` | String | Unique anomaly event identifier. |
| `detection_timestamp` | Datetime | Timestamp when anomaly persistence criteria was satisfied. |
| `dma_id` | String | Affected District Metered Area. |
| `severity` | String | Categorical: `[LOW, MEDIUM, HIGH, CRITICAL]`. |
| `anomaly_type` | String | Categorical: `[UNEXPLAINED_WATER_LOSS, ABNORMAL_PRESSURE_DROP, SENSOR_FAULT]`. |
| `observed_flow` | Float | Actual recorded inflow ($m^3/h$). |
| `expected_flow` | Float | Model-forecasted uncompromised baseline inflow ($m^3/h$). |
| `residual_flow` | Float | Discrepancy: $Q_{\text{observed}} - Q_{\text{expected}}$ ($m^3/h$). |
| `uncertainty_lower` | Float | 95% lower confidence bound of expected flow. |
| `uncertainty_upper` | Float | 95% upper confidence bound of expected flow. |
| `candidate_nodes` | String (JSON) | Ranked array of top candidate junction nodes with confidence scores. |
| `candidate_zones` | String (JSON) | Ranked array of candidate DMA sub-zones. |
| `supporting_evidence`| String | Human-readable engineering rationale (e.g. "Residual exceeded 4.2 sigma with concurrent 1.8m pressure drop at node n12"). |
